# Laundry Advisor Project

A java software that takes inputs from the user to recommend a laundry cycle.

## The Problem

Help students with making the right laundry selection. 
Many students do their own laundry for the first time here in college, myself included. 
I still feel like I have to call my mom each time I do my laundry to not to ruin my clothes. 

## How It Works

A simple java program that gets input from the user and returns the laundry selection as an output. 
Input will be like multiple choice. Asking the user about their load, color of the laundry, type of clothes.

![System diagram](https://drive.google.com/file/d/1lDmIUt96bf9Jt2X5Am4d8EfthcCJIcZd/view?usp=sharing)

## Tech Stack

- Language: Java
- Libraries: Built in Java Scanner Lirary


## MVP Scope

- Console based user input.
- Input parameter:
  1. Load Size
  2. Color
  3. Fabric and clothing type
  4. Dirt level
- Input validation: Checking if the input is valid or not.
- Building logic and displaying the recommendation.
